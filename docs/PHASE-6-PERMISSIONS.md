# Phase 6 Permission Boundaries

| Capability | Director | Adviser | Support Agent | Compliance Admin | Chapter Admin | Owner |
|---|---:|---:|---:|---:|---:|---:|
| Create shared chapter ticket | Yes | Yes | No | No | No | No |
| Create Adviser-private ticket | No | Yes | No | No | No | No |
| Read shared chapter ticket | Assigned chapter | Assigned chapter | Yes | Yes | Yes | Yes |
| Read Adviser-private ticket | Creator only | Creator only | Yes | Yes | Yes | Yes |
| Reply to accessible ticket | Yes | Yes | Yes | Yes | Yes | Yes |
| Add internal staff note | No | No | Yes | Yes | Yes | Yes |
| Assign or escalate ticket | No | No | Yes | Yes | Yes | Yes |
| Publish chapter notice | No | No | No | Yes | Yes | Yes |
| Delete support records | No | No | No | No | No | Owner only |

All chapter access additionally requires a verified Firebase email and an active chapter membership.
